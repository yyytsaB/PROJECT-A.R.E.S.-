## Contracts and decisions
- **Seams 4/5:** `durationSec` is a nonnegative finite number in completed input and saved sessions, normalized to zero for legacy/missing runtime input. `formatDurationMmSs(durationSec)` floors fractional seconds, pads minutes/seconds (minutes may exceed 59), rejects negative/nonfinite values. Seed durations span 45–900 seconds. `bodyWeightKg` is finite and positive, default 78. Loading old schema-version-1 missions adds missing fields without losing sessions/queue; explicit invalid values remain invalid.
- **Seam 6, arena:** `elapsedSeconds` counts running wall time only (including fractional remainders across pause/resume), resets per new session/exercise, survives stop, and saves with the workout. A one-second timer updates independently of camera frames. `formFeedback` is “Spine aligned” only with visible analysis and no active fault alerts. `voiceEnabled`/`setVoiceEnabled` alias the existing voice contract; `visualOverlayEnabled` defaults true and controls canvas overlays, never visible text alerts. Keep the existing `onCompleted(state)` contract and pass duration as an additional callback argument.
- **Seam 6, history:** date ranges `LAST_7_DAYS | LAST_14_DAYS | LAST_30_DAYS | ALL`, UTC calendar windows ending at injected `nowIso`, default ALL; page size 10, one-based page, at least one page for empty results. Search/range changes reset page; state changes clamp it. Sort newest first. Status GREEN requires >=90 form and no captured fault flags, YELLOW >=75, otherwise RED; these are demo form labels, not medical assessments. Select a session to expose duration, sets/reps, load/volume, form/symmetry, faults and snapshot replay/diagnostic. Existing direct snapshot replay remains available.
- **Seam 6, analytics:** selectable 7/14/30-day chart windows (default 30) crop the existing rolling-30-day score series; do not redefine historical retention. Expose matching visible volume total/series, preserve full report JSON/CSV contracts, offer browser print/Save as PDF, announce download initiation with “Health telemetry report exported.” Printing opens a dialog and does not claim a PDF was saved.
- **Seams 3/6, journey:** milestone `description` is nonempty static catalog content. “View all badges” toggles unlocked/locked milestone descriptions.
- **Seams 4/5/6, settings:** measure UTF-8 serialized mission cache (`localCacheBytes`) separately from queue/snapshot JSON sizes, not disk quota or actual wire traffic. All KB are decimal. Validate profile name, body weight and each Earth baseline with associated messages; valid existing field updates remain persisted, and Save / Apply validates and confirms. Every UI clear action first opens an accessible warning with Confirm/Cancel; only confirmation wipes data.
- **Seams 3/5/6, dashboard:** catalog `scheduledTime` uses HH:MM sample times, explicitly a demo schedule. Completion checkboxes persist per UTC mission date; saving a workout marks that day's exercise complete, manual checkboxes never create workout telemetry. Primary “INITIATE TODAY'S SESSION” launches the first unfinished resistance exercise (first resistance exercise if all complete), using the existing simulator path.
- **Seam 6, navigation:** simple section links expose active page state and update `document.title` (e.g. Dashboard — A.R.E.S.). Keep all semantic sections available in the shared testbench to preserve cross-module journeys. Add a keyboard-usable “Skip to main content” link with a focusable main target.
